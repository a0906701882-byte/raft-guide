# RAFT 指南

繁體中文《Raft》Android 離線百科與智慧搜尋。

## 離線智慧助手
- 完全使用 APK 內建資料，不呼叫 Gemini、Cloudflare Worker、Google 搜尋或其他網路服務。
- 不需要 API 金鑰，也不需要網路權限。
- 以物品名稱、英文名稱、用途、取得方式、配方與常見問法進行本機檢索。
- 提供開局、生存、淨水、烹飪、木筏擴建、研究、海底採集、種植、動物、導航、故事探索、交易站、回收機與多人遊玩等主題提示。
- 找不到可靠資料時會提示資料不足，不會將猜測當成遊戲事實。

## 既有功能
- 一般模式／創造模式切換
- 物品百科與分類篩選
- 收藏
- 料理、動物、藍圖、島嶼與新手指南
- 繁體中文介面與深色主題
- 清單採用 LazyColumn，避免一次建立全部卡片

## 資料範圍
本專案持續擴充物品與攻略資料。部分物品配方仍以遊戲內配方表為準；未逐項核對的材料數量不會編造。離線資料不會自動更新，遊戲更新後需透過 App 更新補充資料。

## 建置 APK
GitHub Actions 工作流程：`.github/workflows/build-apk.yml`。推送到 main 後會執行 Release APK 建置。請到 Actions 最新成功的執行紀錄下載 `RAFT-GUIDE-release-apk` Artifact。

目前尚未完成實機安裝與滑動效能測試；建置成功不等於已通過實機測試。
