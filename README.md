# RAFT GUIDE

繁體中文 Raft 離線指南 Android 專案。

## 目前已加入
- 一般模式／創造模式切換介面
- 物品分類與中文、英文、用途搜尋
- 物品詳細頁：用途、取得方式、材料／配方提示
- 收藏清單
- 新手生存指南
- 故事島嶼簡介
- 深色主題與手機底部導覽
- GitHub Actions 自動產生 Android Debug APK

## 重要說明
目前內建的是擴充中的常用物品資料集，並非已逐項核對的完整遊戲 201 項物品資料庫。部分配方以「依遊戲內配方」提示，請以遊戲內研究與製作選單為準。物品圖示目前使用表情符號，尚未加入正式遊戲圖片。一般／創造模式目前提供介面切換，物品清單尚未依模式完全分流。

## 產生 APK
到 GitHub Actions，開啟最新的 **Build Android APK** 工作流程；成功完成後，從該次執行下載 **RAFT-GUIDE-debug-apk** Artifact。

專案尚未經人工安裝測試；使用者要求本次先不進行測試，因此不宣稱 APK 已成功安裝或執行。
