# RAFT 指南線上 AI 部署（Cloudflare Workers + Gemini）

這個後端只接受 Raft 遊戲問題，會使用 Gemini 生成回答與 Google 搜尋 grounding。Android App 不會存放 Gemini API 金鑰。

## 先準備
- Gemini API 金鑰（由家長／監護人協助建立與管理；可能產生 API 用量費用，請先查看 Google AI Studio 的方案與配額）
- Cloudflare 帳號（由家長／監護人協助管理）

## 部署 Worker
1. 登入 Cloudflare Dashboard，進入 **Workers & Pages**。
2. 建立一個 Worker，名稱可用 `raft-guide-ai`。
3. 開啟 Worker 的程式碼編輯器，將本資料夾的 `worker.js` 完整內容貼入，儲存並部署。
4. 進入 Worker 的 **Settings / Variables**（設定／變數）。
5. 新增 Secret，名稱必須是 `GEMINI_API_KEY`，值貼上 Gemini API 金鑰。不要把金鑰放在程式碼、Android App、README 或公開 GitHub。
6. 儲存後重新部署 Worker。
7. 複製 Worker 提供的 HTTPS 網址，通常格式為 `https://你的-worker名稱.你的帳號.workers.dev`。

## 連接 Android App
1. 安裝由最新 GitHub Actions 成功建置的 APK。
2. 開啟「AI問答」。
3. 在「雲端 AI 網址」欄貼上 Worker 的 HTTPS 網址。
4. 詢問 Raft 遊戲問題。網址會保存在這台手機，Gemini 金鑰仍只保存在 Worker Secret。

## 安全與限制
- 不要把 Gemini API 金鑰貼到 ChatGPT 對話或 GitHub。
- 不要公開分享 Worker 管理權限。
- 此版本有 Raft 主題分類與系統規則，但任何 AI 主題限制都不是絕對防護；回答仍需核對遊戲內資料。
- 搜尋來源若由 Gemini 回傳，App 會顯示可開啟的參考來源。
- 後端未設定自訂使用者登入或配額限制；正式公開分享 Worker 前，應先設定使用量限制與監控，避免他人濫用 API。
